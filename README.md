# Universal Resume AI - Intelligent Interview & Resume Architect

A modern, universal resume platform that interviews job seekers step-by-step—beginning from profile photo (PFP) and global photo etiquette down to quantifiable metrics, education, and keywords—and dynamically matches them with the highest-converting resume architecture for their industry.

## 🚀 Key Features

### 1. Interactive Career Interview Wizard
- **Step-by-Step Guided Interview**: Acts as an AI Career Consultant (`Alex`).
- **Phase 1: Profile Picture (PFP) & Regional Etiquette**:
  - Educational guidance on ATS & regional norms (e.g., US/UK anti-bias compliance vs. European/Asian dossier customs).
  - Photo upload, shape framing (Circle, Rounded, Square), visibility toggle, or sample avatar picker.
- **Phase 2: Contact & Identity**: Full name, title, email, phone, location, LinkedIn, GitHub, website.
- **Phase 3: Format Determination Engine**:
  - Dynamically evaluates user's target industry, seniority level (Student to C-Suite), and target region.
  - Generates a Match Confidence score and itemized justification for why a specific layout will succeed.
- **Phase 4: Executive Elevator Pitch**:
  - AI prompt presets: *Impact-Driven*, *Leadership & Exec*, *Tech & Architect*, and *Early Career*.
- **Phase 5: Employment History & Accomplishments**:
  - Google XYZ Formula methodology (*Accomplished [X] as measured by [Y] by doing [Z]*).
  - High-impact power verbs list (`Spearheaded`, `Architected`, `Optimized`, `Scaled`, etc.).
- **Phase 6: Skill Clusters & Keywords**:
  - Grouped categories (Languages, Frameworks, Cloud, Leadership, Tools).
- **Phase 7: Education & Academics**:
  - Degrees, institutions, honors, graduation dates, and relevant coursework.
- **Phase 8: Featured Projects**:
  - Project name, tech stack, deployed URL, and impact description.
- **Phase 9: Certifications & Languages**:
  - Credentials (AWS, PMP, CFA) and multilingual CEFR ratings.
- **Phase 10: Suitability Report**:
  - Summary audit and confetti celebration.

### 2. Universal Resume Architectures (6 Templates)
1. **Modern ATS Pro**: Single-column, 100% ATS parser compliant, ideal for Tech, Software Engineering, and Corporate.
2. **Executive Ivy / Wall Street**: Classic serif (Merriweather), authoritative Harvard/Wharton standard for VP, Directors, Finance, and Consulting.
3. **Creative Studio & Dynamic**: Asymmetrical two-column sidebar layout highlighting aesthetics, visual portfolio, and personal branding.
4. **Minimalist Nordic**: Light lines, breathable whitespace, modern typography; ideal for entry-level and career switchers.
5. **Tech Terminal / Silicon**: Monospace touches, code tags, and project-first layout for DevOps and Backend engineers.
6. **International Europass / Compact**: Structured 2-column with photo badge and CEFR language ratings for European and global markets.

### 3. Studio & Live Editing
- **Live Split-Screen Canvas**: Real-time side-by-side rendering as you answer questions.
- **ATS Compatibility Audit**: Real-time score calculator (0-100%) grading metrics, keyword density, contact completeness, and action verbs.
- **Theme Palettes & Typography**: 8 color schemes (Cobalt, Slate, Emerald, Indigo, Purple, Teal, Crimson, Monochrome) and 5 font pairings.
- **Print & PDF Export**: Custom `@media print` CSS engine for single or multi-page A4 and Letter exports.
- **Pre-filled Presets**: 5 industry profiles ready for 1-click loading.
- **Local Persistence & JSON Backup**: Auto-saves to `localStorage` and supports full JSON import/export.

## 🛠️ Technology Stack
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Effects**: Canvas Confetti
